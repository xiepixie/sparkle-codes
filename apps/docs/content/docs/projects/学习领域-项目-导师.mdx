## 第四阶段：输出作品集（Month 8-10）

**目标**：为考研复试或联系导师准备**可展示的技术成果**。

### 建议做的 2 个项目

**项目 1：DreamerV3 复现 + 改进实验（世界模型方向）**

- 复现 DreamerV3 在标准 benchmark（Atari 或 DMControl）上的结果
- 做 1-2 个改进实验（如换不同的表征学习方法、加 JEPA 式的 latent prediction）
- 写一份技术报告放 GitHub
- **联系导师时附上这个作为"我已经开始做了"的证据**

**项目 2：Lean + LLM 的数学定理自动证明（System 2 方向）**

- 用 Lean Copilot 或 LeanAide 跑通基础流程
- 挑一个本科数学中你熟悉的定理（如泰勒展开的收敛性）尝试形式化
- 体验"神经网络 + 形式验证"的完整链路
- 这个项目你的数学背景会成为独特优势

## 学习建议

**第一阶段，先学"经典世界模型"。**

从 **World Models → DreamerV3 → MuZero** 这条线走，重点吃透 latent state、dynamics model、reward/value prediction、planning / imagination rollout 这些核心概念。这个阶段你的机器绰绰有余。

**第二阶段，做"小而完整"的复现。**

优先选 **CartPole、Pendulum、CarRacing、Atari 小规模实验** 这类环境，目标不是把分数刷到论文水平，而是把训练管线跑通、把 ablation 做明白。DreamerV3 本身就强调跨任务鲁棒和较低的调参门槛，这正适合个人学习。

**第三阶段，再碰"更现代的世界模型"。**

到那时你可以把重点放在 **视频预测、action-conditioned generation、embodied/world simulator** 这些方向，但更适合做 **读论文 + 跑预训练模型 + 小数据微调/裁剪版实验**。
